# حسن‌گرام — HssNGram

<p align="center">
  <img src="apps/web/public/icons/icon-192.png" width="96" alt="HssNGram" />
</p>

پیام‌رسان خصوصی خانواده و دوستان، شبیه تلگرام، برای میزبانی روی **ابر آروان**.
نام انگلیسی پروژه: **HssNGram** — دامنه هدف: `hssngram.hssn.my.id`

---

## چه چیزهایی دارد؟

- **گفتگوی خصوصی و گروهی** با نقش‌های سازنده/مدیر/عضو
- **پیام متنی، پاسخ (Reply)، ویرایش، حذف برای همه، حذف برای من، هدایت (Forward)، سنجاق، واکنش ایموجی**
- **ارسال فایل** (عکس، ویدیو، صدا، سند) تا ۲۰۰ مگابایت و پخش درون‌برنامه‌ای
- **پیام صوتی** با ضبط مستقیم در مرورگر
- **تماس صوتی و تصویری WebRTC** یک‌به‌یک و **گروهی تا ۴ نفر** + اشتراک صفحه + قطع میکروفون/دوربین
- **وضعیت آنلاین، «در حال نوشتن»، تیک خوانده‌شدن، شمارنده خوانده‌نشده، آرشیو گفتگو**
- **جستجوی پیام** در کل حساب و **درون هر گفتگو** (فارسی، full-text پستگرس)
- **اعلان Push** (Web Push) وقتی برنامه بسته است
- **ثبت‌نام با شناسه ۸ رقمی + تأیید ادمین**
- **صفحهٔ «چت با ادمین»** (`/support`): هر بازدیدکننده بدون حساب پیام می‌دهد؛ ادمین همان‌جا برایش حساب ۸ رقمی می‌سازد و گفتگو به آن حساب وصل می‌شود
- **مدیریت کاربران توسط ادمین**: دیدن، افزودن مستقیم، غیرفعال‌سازی و حذف کامل
- **پنل مدیریت**: صندوق پشتیبانی، تأیید/رد کاربران، کدهای دعوت، آمار
- **رابط فارسی RTL**، حالت تاریک/روشن، PWA و نصب روی موبایل

## ورود پیش‌فرض مدیر

| مورد | مقدار |
| --- | --- |
| شناسه ورود | `10000000` |
| گذرواژه | `427726` |
| نام نمایشی | حسن |

> بعد از اولین ورود از «تنظیمات → تغییر گذرواژه» عوضش کنید.
> کاربران جدید با شناسه ۸ رقمی خودشان ثبت‌نام می‌کنند و تا تأیید شما در «پنل مدیریت» نمی‌توانند وارد شوند.

## معماری

```
مرورگر (React + Vite, RTL)
   │  REST (/api)  +  WebSocket (Socket.IO)  +  WebRTC (P2P)
   ▼
Node.js 24 / Express 5 / Socket.IO  ──►  PostgreSQL (کاربر، پیام، گروه، تماس، پشتیبانی)
   │                                   └─►  آبجکت‌استوریج آروان (فایل‌ها) یا دیسک محلی
   └─►  coturn (TURN) برای تماس‌ها
```

- تک‌سرویس: API و وب‌اپ در یک کانتینر روی پورت `8080`.
- فایل‌ها یا روی **Object Storage آروان** (S3 سازگار) یا دیسک سرور.
- تماس‌ها P2P هستند؛ سرور فقط سیگنالینگ می‌کند و TURN فقط وقتی NAT سخت باشد ترافیک را عبور می‌دهد.

## اجرای محلی (بدون نصب پستگرس)

```bash
npm install
npm run db:dev                 # PGlite روی 127.0.0.1:55432
cp apps/server/.env.example apps/server/.env   # مقادیر محلی را تنظیم کنید
npm run migrate
npm run seed                   # ادمین 10000000 / 427726
npm run dev                    # API روی :8080 و Vite روی :5173
```

سپس <http://localhost:5173> را باز کنید. صفحهٔ پشتیبانی: `/support`.

نسخهٔ تولیدی:

```bash
npm run build
npm start                      # http://localhost:8080
```

## استقرار روی اروان

راهنمای گام‌به‌گام: [`docs/arvan-deploy.md`](docs/arvan-deploy.md)

```bash
# روی سرور ابری آروان
git clone <repo> /opt/hssngram && cd /opt/hssngram
cp apps/server/.env.example apps/server/.env   # JWT_SECRET, POSTGRES_PASSWORD, TURN_SECRET, PUBLIC_URL
docker compose up -d --build
docker compose exec app node apps/server/dist/cli/seed.js
```

`Caddy` گواهی HTTPS را برای `hssngram.hssn.my.id` خودکار می‌گیرد و WebSocket بدون تنظیم اضافه کار می‌کند.

## تنظیمات مهم (`.env`)

| کلید | توضیح |
| --- | --- |
| `DATABASE_URL` | رشته اتصال پستگرس |
| `JWT_SECRET` | حداقل ۳۲ نویسه تصادفی |
| `PUBLIC_URL` | `https://hssngram.hssn.my.id` |
| `REGISTRATION_MODE` | `open` (پیش‌فرض) / `invite` / `closed` |
| `REQUIRE_APPROVAL` | `true` یعنی ثبت‌نام بدون تأیید ادمین فعال نمی‌شود |
| `STORAGE_DRIVER` | `s3` برای آبجکت‌استوریج آروان یا `local` |
| `S3_ENDPOINT` | `https://s3.ir-thr-at1.arvanstorage.ir` (منطقه سیمین) |
| `TURN_URLS` / `TURN_SECRET` | برای تماس‌ها پشت NAT سخت |
| `MAX_CALL_PARTICIPANTS` | سقف نفرات تماس (پیش‌فرض ۴) |
| `VAPID_*` | برای اعلان Push (`npx web-push generate-vapid-keys`) |
| `MAX_UPLOAD_MB` | سقف حجم فایل (پیش‌فرض ۲۰۰) |

## نقشهٔ راه بر اساس تحقیق تلگرام

دو سند پژوهشی کامل: [`docs/telegram-features.md`](docs/telegram-features.md) و [`docs/telegram-admin-calls.md`](docs/telegram-admin-calls.md) — بیش از ۱۱۰ کیلوبایت مشخصات، ماتریس مجوزها، طرح داده و فهرست محدودیت‌های وب.

قدم‌های بعدی به‌ترتیب اولویت:

1. **اعتماد و کنترل**: تیک خواندن تنظیم‌پذیر، مخفی‌کردن آخرین بازدید، بلاک، محدودیت پیام از غریبه‌ها
2. **زمان و وضعیت**: ارسال زمان‌بندی‌شده، پیام خودتخریب (TTL)، ارسال بی‌صدا، پیش‌نویس همگام
3. **ساختار گروه**: کانال پخش، مجوزهای ریز مدیران (`rights jsonb`)، لینک دعوت با انقضا، صف تأیید عضویت
4. **قالب‌های محتوا**: آلبوم چندعکسی، استیکر/GIF، نظرسنجی، لوکیشن
5. **سنگین‌ها**: SFU برای تماس بیش از ۴ نفر، ربات‌ها، جستجوی پیشرفته

## امنیت

- گذرواژه‌ها با `scrypt`؛ توکن دسترسی ۲۰ دقیقه‌ای + refresh چرخشی با تشخیص استفادهٔ مجدد.
- فایل‌ها با توکن امضاشده و کوتاه‌عمر؛ لینک بدون امضا `403`.
- محدودیت نرخ روی ورود/ثبت‌نام/ارسال پیام/آپلود/پشتیبانی.
- هدرهای امنیتی و CSP، کوکی `httpOnly`، `trust proxy` پشت Caddy.
- فایل‌های اجرایی (`.exe`, `.bat`, `.ps1`, …) رد می‌شوند.
- گفتگوی مهمان با کوکی امضاشده و توکن تصادفی ۹۰ روزه نگه داشته می‌شود و به حساب کاربری ارتقا می‌یابد.
